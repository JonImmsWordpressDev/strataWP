Portfolio, team, testimonial and case-study content types for the StrataWP Advanced theme.

== Description ==

Companion plugin for the StrataWP Advanced theme. It registers the content types the theme's blocks and layouts display, so they stay available if you switch themes.

* Portfolio (`portfolio`) with Portfolio Categories and Portfolio Tags
* Team Members (`team`) with Departments
* Testimonials (`testimonial`)
* Case Studies (`case_study`) with Industries and Services

The StrataWP Advanced theme works without this plugin; the portfolio and team blocks simply render nothing until it is active.

== Installation ==

1. Copy the `strata-advanced-content` folder into `wp-content/plugins`.
2. Activate StrataWP Advanced Content under Plugins.

Activation flushes rewrite rules, so the content type URLs work straight away.
