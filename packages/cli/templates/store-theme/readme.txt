== Description ==

StrataWP Store Theme is a block theme optimized for WooCommerce. It provides product showcase patterns, cart integration and storefront layouts built on the StrataWP framework. WooCommerce is required for the store features.

== Installation ==

1. In your WordPress admin, go to Appearance > Themes and click Add New.
2. Click Upload Theme and choose the theme zip file.
3. Click Install Now, then Activate.
