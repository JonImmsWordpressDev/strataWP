A basic example theme showcasing StrataWP framework capabilities

== Description ==

StrataWP Basic Theme is a block theme built on the StrataWP framework. It ships with Full Site Editing templates, template parts and block patterns, and shows how a TypeScript and Vite powered theme fits together.

== Installation ==

1. In your WordPress admin, go to Appearance > Themes and click Add New.
2. Click Upload Theme and choose the theme zip file.
3. Click Install Now, then Activate.
